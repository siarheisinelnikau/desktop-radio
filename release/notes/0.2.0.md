This is the first public release of Desktop Radio for Windows 10 and 11 (x64). Download `DesktopRadio-v0.2.0.exe` and run it directly. The Rust runtime, audio decoders, and station catalog are built into the executable.

- Open the player from the Windows notification area, switch stations, and keep listening while the panel is hidden.
- Browse 268 stations from Belarus, Russia, Kazakhstan, and around the world. Search by name or frequency, save favorites, and choose the display order.
- Adjust the sound with a ten-band equalizer and show a live spectrum or waveform. Choose graphite or amber and switch between English, Russian, and Kazakh.
- See track titles when the station supplies metadata and resume the last station at startup if enabled.
- Check for newer releases in Settings and install verified updates from the app. The companion `.sha256` file also supports manual integrity verification.
